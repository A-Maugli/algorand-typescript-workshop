# Fun homework

1. Create a box storage named `github` and store your GitHub username in the box.
2. Modify the deposit method to take in the GitHub username argument and store it in the created box.
3. Deploy your app to testnet, call the deposit method to store your GitHub username.
4. Note your deployed Application ID for the assignment submission form.
5. Include a file named workshop-submission.txt in the root with only your Application ID inside.
6. Push your code again to the same GitHub repo.
7. Submit your project via the Assignment Submission Form. Include your GitHub username, repo link and Application ID. See the details in [Workshop Certification & Prize Eligibility Criteria](https://docs.google.com/document/d/1CxsY6GAHUngFOAxp6YtBTf3vf7KAI0X0Jqn3T-ZVRBw/edit?tab=t.0)
